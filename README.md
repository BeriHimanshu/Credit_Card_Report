# Credit Card Data Analysis & Reporting

This project performs a comprehensive data-analysis and reporting workflow on credit card related datasets to extract insights and support decision-making.  

## 🧮 Project Overview  
In this repository, you’ll find:  
- Multiple related CSV datasets (customer details, credit card transactions, etc.).  
- A notebook or analysis script that cleans, explores, and visualizes the data.  
- A final report (PDF) summarizing key findings and next-steps.

### Key Objectives  
- Explore the relationships among customer demographics, credit-card usage and credit behaviour.  
- Clean and preprocess the data (handling missing values, encoding, etc.).  
- Visualize trends, patterns and anomalies using plots and dashboards.  
- Produce a well-documented report that highlights insights and recommendations.

## 📂 Datasets & Files  
- `credit_card.csv` — Main credit card dataset.  
- `cust_add.csv` — Customer address information.  
- `customer.csv` — Additional customer demographic data.  
- `cc_add.csv` — Additional credit-card account information.  
- `Credit_report.pdf` — The final generated report summarizing the analysis.  
- `README.md` — This file: documentation and project overview.
